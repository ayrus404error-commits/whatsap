# Security policy

Please **don't open a public issue** for security problems, for example ways to
read someone's messages or keys, or to run code through a crafted message.

Report them privately through GitHub instead: **Security → Report a
vulnerability** on this repository. Include steps to reproduce and the app
version (shown at the bottom of the Settings page). You should hear back within a week.

Problems in the WhatsApp protocol implementation itself are best reported
upstream to [whatsmeow](https://github.com/tulir/whatsmeow/security).

Only the latest release gets security fixes.
